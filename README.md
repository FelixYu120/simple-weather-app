# 🌤️ Weather App

A simple weather application built with **Python** and **PyQt5**, allowing users to check current weather conditions for any city. The app displays temperature, weather description, and an emoji representing the weather.

---

## 🚀 Features

- Enter a city name and fetch current weather.
- Displays:
  - Temperature in Celsius.
  - Emoji icon based on weather.
  - Short description (e.g. "clear sky").
- Built with a clean PyQt5 interface.

---

## 🧰 Requirements

- Python 3.7+
- `PyQt5`
- `requests`

### Install with:

```bash
pip install -r requirements.txt
